Partie 1 stéganographie

Pour ce challenge, on nous donne dans l'énoncé une partie d'un code Python :

from random import randint
message = ""
for iterateur in (cle_instagram, cle_twitter, cle_discord):
    for elt in iterateur():
        message += "?"
        cle = None
        while cle != 0x42:
            message = message[:-1]
            cle = randint(0, 10000)
            message += chr(elt ^ (cle & 0xff))
            print(message)

On peut faire plusieurs remarques sur ce code :

  • Il y a manifestement des données manquantes, les clés Twitter, Instagram et Discord.
  • Si la clé est différente de 0x42, un message est généré aléatoirement.

Après un peu de recherche sur les réseaux, j'ai remarqué dans l'arrière-plan des poste qui annoncer l'ouverture des qualification les donner manquant légèrement flouter, mais toujours lisible dans la mesure où on connaît leurs valeurs possibles (ce sont des chaînes hexadécimales.) par exemple l'image discorde.
